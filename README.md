# Employee Salary Management

A web tool for ACME's HR team to manage employee salary data across 10,000 employees and multiple countries — and to **answer questions about how the organisation pays its people**, with every figure normalised to a common currency.

> Built as a take-home assessment. Emphasis on clear thinking, right-sized design, clean tested code, and an honest record of how it was built.

**Stack:** Java + Spring Boot · PostgreSQL · React (Vite) · TDD throughout.

Documentation lives in [`docs/`](docs/) — start with the [requirements](docs/requirements.md).
